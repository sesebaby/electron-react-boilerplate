## 发现的问题

### 🔴 高优先级问题

#### 1. 库存数据不一致问题
**模块**：销售订单管理 ↔ 库存管理
**问题描述**：
- 库存概览显示A4复印纸在总仓库有85.00库存
- 但在销售订单创建时显示"可用库存 0"
- 导致无法创建包含该商品的销售订单

**影响**：
- 阻止正常的销售订单创建流程
- 可能影响业务操作的连续性
- 用户体验受到影响

**重现步骤**：
1. 进入库存概览 → 显示有库存数据
2. 进入库存调整 → 选择A4复印纸 → 显示总仓库库存85.00
3. 进入销售订单 → 新建订单 → 添加A4复印纸 → 提示"库存不足：产品 A4复印纸 可用库存 0，订单需求 X"

**可能原因**：
- 不同模块使用不同的库存计算逻辑
- 库存数据同步机制存在问题
- 可用库存与实际库存的定义不一致
- 数据库查询逻辑差异

**最新发现**：
- 库存报表显示A4复印纸：当前库存85，可用85，预留0
- 这进一步证实了不同模块间库存查询逻辑的不一致性

**建议解决方案**：
1. 统一库存计算逻辑，确保所有模块使用相同的库存查询方法
2. 检查库存数据同步机制
3. 明确定义"可用库存"与"实际库存"的区别
4. 添加库存数据一致性检查机制

### ✅ 修复1：库存数据不一致问题
**修复时间**：2025-07-06
**修复方案**：
1. 修改销售订单服务 (`src/services/business/salesOrderService.ts`)
   - 替换硬编码的 `'default-warehouse'` 为动态获取默认仓库
   - 添加 `warehouseService.findDefault()` 调用
   - 导入 warehouseService 依赖

**修复代码**：
```typescript
// 修复前
const warehouseId = 'default-warehouse'; // 硬编码

// 修复后
const defaultWarehouse = await warehouseService.findDefault();
if (!defaultWarehouse) {
  throw new Error('系统未配置默认仓库，无法检查库存');
}
const warehouseId = defaultWarehouse.id;
```

**验证结果**：
- ✅ A4复印纸现在可以正常添加到销售订单中
- ✅ 库存检查功能正常工作
- ✅ 金额自动计算功能正常（10 × ¥25 = ¥250）

### ✅ 修复2：库存概览商品名称显示问题
**修复时间**：2025-07-06
**修复方案**：
1. 修改库存概览组件 (`src/components/Inventory/InventoryOverview.tsx`)
   - 在最近库存变动中使用 `productService.findById()` 获取商品信息
   - 导入 productService 依赖
   - 异步获取商品名称

**修复代码**：
```typescript
// 修复前

return {
  id: stock.id,
  productName: product ? product.name : `未知商品-${stock.productId}`,
  // ...
};
```

**验证结果**：
- ✅ 最近库存变动现在显示真实商品名称
