## 🎯 重构方案重新评估

### 方案对比分析

| 方案 | 服务数量 | 复杂度 | 维护成本 | 功能完整性 | 学习成本 | 推荐度 |
|------|---------|-------|---------|-----------|---------|--------|
| **当前方案** | 1个巨型 | 极高 | 极高 | 完整 | 很高 | ❌ |
| **按模块拆分** | 8个小服务 | 高 | 高 | 完整 | 高 | ⚠️ |
| **领域服务方案** | 3个领域服务 | 中 | 低 | 完整 | 低 | ✅ |
| **最简方案** | 1个简化服务 | 低 | 最低 | 完整 | 最低 | 🤔 |

### 最终选择：领域服务方案

**选择理由**：
1. **符合业务特点**：进销存是高度集成的业务，产品、库存、基础数据密切相关
2. **平衡复杂度**：既解决了过度工程化，又保持了合理的职责分离
3. **保证一致性**：相关业务逻辑在同一服务内，避免跨服务事务问题
4. **易于维护**：3个服务比8个服务更容易管理和理解

### 架构简化
```
当前架构（7层）: UI → Hook → ServiceManager → InventoryService → DatabaseManager → ElectronDatabase → IPC → SQLite
目标架构（4层）: UI → 领域服务 → 直接IPC调用 → SQLite
```

### 服务拆分策略
```
InventoryService (1613行) → 3个领域服务 (750行总计)
```

### 1. InventoryDomainService 核心方法

```typescript
export class InventoryDomainService {
  // 获取产品及库存信息
  async getProductsWithStock(filter?: ProductFilter): Promise<DomainServiceResult<ProductWithStock[]>> {
    try {
      const query = `
        SELECT p.*, s.currentStock, s.availableStock, s.minStock, s.maxStock,
               (s.currentStock * p.salePrice) as totalValue
        FROM products p
        LEFT JOIN inventory_stocks s ON p.id = s.productId
        WHERE p.status != 'deleted'
      `;
      
      const products = await window.electronAPI.dbQuery(query);
      
      const productsWithStock = products.map(row => ({
        ...row,
        isLowStock: row.currentStock <= row.minStock,
        isOutOfStock: row.currentStock === 0
      }));
      
      return { success: true, data: productsWithStock };
    } catch (error) {
      return { success: false, error: error.message };
    }
  }

  // 库存入库操作（事务性）
  async stockIn(request: StockOperationRequest): Promise<DomainServiceResult<InventoryTransaction>> {
    try {
      await window.electronAPI.dbBeginTransaction();
      
      // 1. 验证产品和仓库存在
      const product = await window.electronAPI.dbGetProduct(request.productId);
      if (!product) throw new Error('产品不存在');
      
      // 2. 更新库存
      const currentStock = await this.getProductStock(request.productId, request.warehouseId);
      const newQuantity = currentStock.data.currentStock + request.quantity;
      
      await window.electronAPI.dbUpdateStock(request.productId, request.warehouseId, {
        currentStock: newQuantity,
        availableStock: newQuantity,
        updatedAt: new Date()
      });
      
      // 3. 创建交易记录
      const transaction = {
        id: uuidv4(),
        productId: request.productId,
        warehouseId: request.warehouseId,
        type: 'in',
        quantity: request.quantity,
        operator: request.operator,
        remark: request.remark,
        createdAt: new Date()
      };
      
      await window.electronAPI.dbCreateTransaction(transaction);
      await window.electronAPI.dbCommitTransaction();
      
      return { success: true, data: transaction };
    } catch (error) {
      await window.electronAPI.dbRollbackTransaction();
      return { success: false, error: error.message };
    }
  }

  // 其他业务方法
  async getLowStockItems(): Promise<DomainServiceResult<ProductWithStock[]>> {
    return this.getProductsWithStock({ lowStock: true });
  }

  async getOutOfStockItems(): Promise<DomainServiceResult<ProductWithStock[]>> {
    try {
      const result = await this.getProductsWithStock();
      if (!result.success) return result;

      const outOfStockItems = result.data!.filter(item => item.isOutOfStock);
      return { success: true, data: outOfStockItems };
    } catch (error) {
      return { success: false, error: error.message };
    }
  }
}
```

```typescript
        if (categoriesResult.success) {
          setCategories(categoriesResult.data || []);
        }
      } catch (error) {
        console.error('加载数据失败:', error);
      }
    };

    loadData();
  }, []);

  const handleCreateProduct = async (productData: CreateProductRequest) => {
    try {
      const inventoryService = domainServiceManager.getInventoryDomainService();
      const result = await inventoryService.createProduct(productData);

      if (result.success) {
        // 重新加载产品列表
        const productsResult = await inventoryService.getProductsWithStock();
        if (productsResult.success) {
          setProducts(productsResult.data || []);
        }
        return { success: true };
      } else {
        return { success: false, error: result.error };
      }
    } catch (error) {
      return { success: false, error: '创建产品失败' };
```
