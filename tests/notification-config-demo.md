# 通知消息级别配置功能演示

## 功能概述

我已经成功在系统设置中添加了消息级别设定功能，用户现在可以：

1. **控制消息显示类型** - 选择显示哪些类型的消息（信息、成功、警告、错误）
2. **快捷重要模式** - 一键切换到只显示重要消息（警告和错误）
3. **自定义配置** - 灵活配置各种通知参数

## 新增功能详情

### 1. 扩展的通知配置接口

```typescript
export interface SimpleNotificationConfig {
  enabled: boolean;                    // 通知总开关
  maxDisplay: 3 | 5 | 10;             // 最大显示数量
  enableSound: boolean;                // 声音提醒
  enabledTypes: NotificationType[];    // 启用的消息类型
  showOnlyImportant: boolean;          // 只显示重要消息模式
}
```

### 2. 消息类型定义

- **信息消息** (info) 💡 - 一般性信息提醒
- **成功消息** (success) ✅ - 操作成功确认  
- **警告消息** (warning) ⚠️ - 需要注意的问题
- **错误消息** (error) ❌ - 操作失败或系统错误

### 3. 显示模式

#### 显示全部模式
- 显示所有类型的消息
- 适合需要完整信息反馈的用户

#### 只显示重要模式  
- 只显示警告和错误消息
- 隐藏一般的信息和成功消息
- 适合希望减少干扰的用户

#### 自定义模式
- 用户可以自由选择要显示的消息类型
- 提供最大的灵活性

## 使用方法

### 访问配置页面
1. 进入系统管理页面
2. 点击"系统设置"标签
3. 选择"通知配置"标签页

### 配置选项

#### 通知总开关
- 控制是否启用整个通知系统
- 关闭后将不显示任何通知

#### 消息级别设置
- **显示全部**：显示所有类型的消息
- **只显示重要**：只显示警告和错误消息  
- **自定义**：手动选择要显示的消息类型

#### 其他设置
- **最大显示数量**：控制顶栏最多显示几条通知（3/5/10条）
- **声音提醒**：新通知时是否播放提示音

#### 配置预览
- 实时显示当前配置状态
- 帮助用户确认设置是否正确

## 技术实现

### 1. 过滤逻辑
- 在 `notificationStore` 中实现消息过滤
- 根据用户配置自动过滤显示的消息
- 支持实时配置更新

### 2. 配置持久化
- 配置自动保存到 localStorage
- 页面刷新后配置保持不变
- 与系统设置统一保存机制

### 3. 向后兼容
- 保持现有通知API不变
- 新功能对现有代码无影响
- 默认配置显示所有消息类型

## 使用场景

### 场景1：减少信息干扰
用户在忙碌时可以开启"只显示重要"模式，只关注警告和错误消息，避免被大量的信息和成功消息干扰。

### 场景2：调试和开发
开发人员可以选择只显示错误消息，专注于问题排查。

### 场景3：日常使用
普通用户可以选择显示所有消息，获得完整的操作反馈。

## 配置示例

```javascript
// 只显示重要消息
notificationHelper.updateConfig({
  showOnlyImportant: true
});

// 自定义显示警告和错误
notificationHelper.updateConfig({
  showOnlyImportant: false,
  enabledTypes: ['warning', 'error']
});

// 检查消息类型是否启用
const isWarningEnabled = notificationHelper.isTypeEnabled('warning');
```

这个功能完全满足了您的需求：可以限制消息的显示类型，默认情况下可以设置为不显示一般操作信息，只显示重要的警告和错误消息。
