### 1.2 逐日消耗数据模型设计 🔄

#### 核心数据结构

```typescript
// 逐日消耗数据项
interface DailyConsumptionItem {
  date: string; // YYYY-MM-DD
  productId: string;
  categoryId: string;
  categoryName: string;
  parentCategoryId?: string;
  parentCategoryName?: string;
  timeSlots: {
    morning: ConsumptionSlotData;   // 早 (06:00-12:00)
    afternoon: ConsumptionSlotData; // 中 (12:00-18:00)
    evening: ConsumptionSlotData;   // 晚 (18:00-06:00)
  };
  dailyTotal: ConsumptionSlotData;
}

// 时间段消耗数据
interface ConsumptionSlotData {
  quantity: number;           // 基础数量
  convertedQuantity?: number; // 换算数量
  amount: number;             // 金额
  transactionCount: number;   // 交易次数
}

// 逐日消耗视图配置
interface DailyConsumptionViewConfig {
  dateRange: {
    startDate: Date;
    endDate: Date;
  };
  displayMode: 'quantity' | 'converted' | 'amount'; // 显示模式
  categoryFilter?: string[]; // 分类筛选
  timeSlotConfig: {
    morning: { start: string; end: string };    // "06:00" - "12:00"
    afternoon: { start: string; end: string };  // "12:00" - "18:00"
    evening: { start: string; end: string };    // "18:00" - "06:00"
  };
}

// 表格数据结构
interface ConsumptionTableData {
  categories: CategoryRowData[];
  dateColumns: string[]; // 日期列表
  totals: {
    categoryTotals: Map<string, ConsumptionSlotData>; // 每个分类的总计
    dateTotals: Map<string, ConsumptionSlotData>;     // 每个日期的总计
    grandTotal: ConsumptionSlotData;                  // 总计
  };
}

// 分类行数据
interface CategoryRowData {
  categoryId: string;
  categoryName: string;
  level: number;
  parentId?: string;
  isExpanded: boolean;
  children?: CategoryRowData[];
  data: Map<string, TimeSlotData>; // key: date, value: 时间段数据
  rowTotal: ConsumptionSlotData;
}

// 时间段数据
interface TimeSlotData {
  morning: ConsumptionSlotData;
  afternoon: ConsumptionSlotData;
  evening: ConsumptionSlotData;
  dailyTotal: ConsumptionSlotData;
}
```

## 技术要点

### 时间段划分逻辑
```typescript
function getTimeSlot(timestamp: Date): 'morning' | 'afternoon' | 'evening' {
  const hour = timestamp.getHours();
  if (hour >= 6 && hour < 12) return 'morning';
  if (hour >= 12 && hour < 18) return 'afternoon';
  return 'evening'; // 18:00-06:00
}
```

### 双层表头实现
- 第一层：日期分组
- 第二层：早、中、晚时间段
- 使用 `colspan` 和 `rowspan` 实现复杂表头

### 数据视图切换
- 数量统计：直接显示出库数量
- 换算数量：使用单位转换服务计算
- 金额统计：数量 × 单价

### FIFO实现要点
- 维护库存批次记录（入库时间、数量、单价）
- 出库时按入库时间顺序消耗
- 更新平均成本计算
