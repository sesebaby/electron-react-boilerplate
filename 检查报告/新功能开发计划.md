# 库存管理系统新功能开发计划

## 项目概述

基于当前简化的通知系统，按优先级依次开发三个新功能：
1. 库存视图卡片模式
2. 物品单位转换系统  
3. 日历式整体视图

## 功能1：库存视图卡片模式

### 功能描述
开发一个新的库存查看界面，采用卡片平铺布局，每个卡片显示一个仓库的信息。

### 技术设计

#### 1.1 组件结构
```
src/pages/InventoryCardView.tsx          // 主页面组件
src/components/Inventory/
├── WarehouseCard.tsx                    // 仓库卡片组件
├── ProductItem.tsx                      // 产品项组件
├── InventoryFilter.tsx                  // 筛选组件
└── InventorySearch.tsx                  // 搜索组件
```

#### 1.2 数据结构
```typescript
interface WarehouseCardData {
  warehouseId: string;
  warehouseName: string;
  products: ProductStockInfo[];
  totalProducts: number;
  lowStockCount: number;
}

interface ProductStockInfo {
  productId: string;
  productName: string;
  sku: string;
  currentStock: number;
  minStock: number;
  unit: string;
  isLowStock: boolean;
}
```

#### 1.3 功能特性
- 响应式网格布局（1-4列自适应）
- 仓库筛选（全部/指定仓库）
- 产品搜索（按名称/SKU）
- 库存状态标识（正常/预警/缺货）
- 卡片内产品列表滚动
- 点击产品跳转详情

#### 1.4 开发任务
1. 创建基础组件结构
2. 实现数据获取逻辑
3. 设计卡片布局样式
4. 添加筛选搜索功能
5. 实现响应式设计
6. 集成路由导航
7. 编写单元测试

### 预估工期：3-4天

## 功能2：物品单位转换系统

### 功能描述
实现物品的包装单位配置功能，在进销存模块中显示转换后数量。

### 技术设计

#### 2.1 数据模型扩展
```typescript
interface ProductUnit {
  id: string;
  productId: string;
  unitName: string;        // 单位名称：个、箱、件、包、盒
  conversionRate: number;  // 转换比率：1箱=24个
  isBaseUnit: boolean;     // 是否基础单位
  createdAt: Date;
  updatedAt: Date;
}

interface Product {
  // 现有字段...
  baseUnit: string;        // 基础单位
  units: ProductUnit[];    // 单位配置
}
```

#### 2.2 组件结构
```
src/components/Product/
├── UnitConfigModal.tsx                  // 单位配置弹窗
├── UnitConverter.tsx                    // 单位转换器
└── UnitDisplay.tsx                      // 单位显示组件

src/services/business/
└── productUnitService.ts                // 单位管理服务
```

#### 2.3 功能特性
- 产品单位配置管理
- 多级单位转换（个→包→箱）
- 进销存数量转换显示
- 单位转换计算器
- 常用单位模板

#### 2.4 集成点
- 商品管理：添加单位配置界面
- 采购管理：显示转换后数量列
- 销售管理：显示转换后数量列
- 库存管理：显示转换后数量列

#### 2.5 开发任务
1. 扩展数据模型和服务
2. 创建单位配置组件
3. 实现转换计算逻辑
4. 集成到现有模块
5. 添加数据验证
6. 编写测试用例

## 功能3：日历式整体视图

### 功能描述
开发综合性日历视图界面，按日期显示采购、销售、库存变动情况。

### 技术设计

#### 3.1 组件结构
```
src/pages/CalendarOverview.tsx           // 日历总览页面
src/components/Calendar/
├── WeeklyCalendar.tsx                   // 周视图组件
├── DayCell.tsx                          // 日期单元格
├── ActivitySummary.tsx                  // 活动摘要
├── CalendarNavigation.tsx               // 导航控制
└── DayDetailModal.tsx                   // 日期详情弹窗
```

#### 3.2 数据结构
```typescript
interface DayActivity {
  date: string;                          // YYYY-MM-DD
  purchaseOrders: number;                // 采购订单数量
  salesOrders: number;                   // 销售订单数量
  inventoryChanges: number;              // 库存变动次数
  totalValue: number;                    // 总金额
  activities: ActivityDetail[];          // 详细活动
}

interface ActivityDetail {
  type: 'purchase' | 'sales' | 'inventory';
  id: string;
  description: string;
  amount: number;
  time: string;
}
```

#### 3.3 功能特性
- 周视图模式（7天一页）
- 周切换导航
- 日期活动统计
- 活动类型图标标识
- 点击查看详情
- 数据导出功能

#### 3.4 开发任务
1. 创建日历组件架构
2. 实现数据聚合逻辑
3. 设计日历界面样式
4. 添加导航控制
5. 实现详情弹窗
6. 集成数据导出
7. 性能优化
