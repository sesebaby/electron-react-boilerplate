# 第一列背景色主题变量统一修改报告

## 📋 修改需求

用户要求将商品列表表格中第一列（商品信息列）的背景颜色与普通单元格（如"分类"列中显示"未分类"的单元格）的背景颜色保持一致，并且要求：

1. **遵循UI设计系统原则**：不使用硬编码颜色值
2. **在主题变量定义文件中修改**：通过修改CSS变量实现
3. **保持主题适配**：确保所有主题都能正确显示

## 🔍 问题分析

### 当前状态分析
- **普通表格单元格**：使用透明背景，显示表格容器的 `var(--surface-background)` 背景色
- **第一列（固定列）**：使用 `var(--card-background)` 背景色
- **视觉不一致**：两者使用不同的CSS变量，导致背景色不一致

### 各主题变量对比

#### 修改前的变量值：
```css
/* 玻璃未来风主题 */
--surface-background: oklch(0.93 0.034 272.788 / 0.25);
--card-background: oklch(0.93 0.034 272.788 / 0.15);  /* 不一致 */

/* 科技暗黑风主题 */
--surface-background: oklch(0.279 0.041 260.031 / 0.15);
--card-background: oklch(0.279 0.041 260.031 / 0.08);  /* 不一致 */

/* 温暖商务风主题 */
--surface-background: oklch(0.987 0.022 95.277 / 0.7);
--card-background: oklch(0.987 0.022 95.277 / 0.5);   /* 不一致 */

/* 黑白精简风主题 */
--surface-background: oklch(0.85 0.01 258.065 / 0.98);
--card-background: oklch(0.85 0.01 258.065 / 1);      /* 不一致 */
```

## 🔧 修改方案

### 技术实现原则
1. **保持CSS变量系统**：继续使用 `var(--card-background)` 作为第一列背景
2. **统一变量值**：将各主题中的 `--card-background` 修改为与 `--surface-background` 相同的值
3. **主题一致性**：确保所有主题都遵循相同的修改原则

### 具体修改内容

**文件**：`src/styles/themes.css`

#### 1. 玻璃未来风主题（第一个定义）
```css
/* 修改前 */
--surface-background: oklch(0.93 0.034 272.788 / 0.25);
--card-background: oklch(0.93 0.034 272.788 / 0.15);

/* 修改后 */
--surface-background: oklch(0.93 0.034 272.788 / 0.25);
--card-background: oklch(0.93 0.034 272.788 / 0.25);  /* 与surface-background保持一致 */
```
