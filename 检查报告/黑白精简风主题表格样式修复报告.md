# 黑白精简风主题表格样式修复报告

## 📋 问题描述

在黑白精简风主题下，表格表头的背景颜色过于浅淡，与表格内容区域的背景色对比度不足，影响视觉层次和用户体验。

### 具体问题
1. **对比度不足**：表头使用的 `--hover-background` 变量颜色过浅
2. **视觉层次不清**：表头与内容区域背景色差异不明显
3. **主题不一致**：黑白精简风主题需要更深的灰色来体现专业感

## 🔍 问题分析

### 原始颜色配置
```css
/* 黑白精简风主题变量 */
--hover-background: oklch(44.6% 0.03 256.802 / 1);     /* 中等灰色 - 表头当前使用 */
--card-background: oklch(0.85 0.01 258.065 / 1);       /* 浅灰色 - 内容区域使用 */
--topbar-background: oklch(0.583 0.024 252.894 / 0.95); /* 深灰色 - TopBar使用 */
```

### 问题根因
- 表头使用的 `--hover-background` 比内容区域的 `--card-background` 更深，但差异不够明显
- 黑白精简风主题需要更强的对比度来体现专业商务感
- 缺少针对该主题的特殊样式优化

## 🔧 解决方案

### 1. 新增主题特定样式

在 `src/styles/theme-adaptations.css` 中为黑白精简风主题添加专门的表格样式：

```css
/* 黑白精简风主题表格样式增强 - 使用更深的灰色提供更好的对比度 */
[data-theme="minimal-monochrome"] .table-header-enhanced {
  background: oklch(0.583 0.024 252.894 / 0.95) !important; /* gray-700/95% - 与topbar一致的深灰色 */
  color: oklch(1 0 0 / 0.9) !important; /* 白色文字确保对比度 */
  text-shadow: none !important; /* 移除阴影保持纯净 */
  border-bottom: 1px solid oklch(0.585 0.233 277.117 / 0.4) !important; /* indigo边框 */
}

[data-theme="minimal-monochrome"] .table-first-column-enhanced {
  background: oklch(0.583 0.024 252.894 / 0.95) !important; /* gray-700/95% - 与表头一致 */
  color: oklch(1 0 0 / 0.9) !important; /* 白色文字确保对比度 */
  text-shadow: none !important; /* 移除阴影保持纯净 */
  border-right: 1px solid oklch(0.585 0.233 277.117 / 0.4) !important; /* indigo边框 */
}
```

### 2. 设计原则

#### 颜色选择
- **表头背景**：使用 `oklch(0.583 0.024 252.894 / 0.95)` (gray-700/95%)
  - 与TopBar背景色一致，保持界面统一性
  - 比内容区域的浅灰色明显更深，提供清晰的视觉层次
  
#### 文字颜色
- **表头文字**：使用 `oklch(1 0 0 / 0.9)` (白色/90%)
  - 在深灰色背景上提供足够的对比度
  - 符合黑白精简风主题的设计理念

#### 边框设计
- **装饰边框**：使用 `oklch(0.585 0.233 277.117 / 0.4)` (indigo-500/40%)
  - 保持与主题的indigo装饰色一致
  - 提供微妙的色彩点缀

### 3. 技术实现

#### 优先级控制
- 使用 `!important` 确保主题特定样式优先于通用样式
- 精确的选择器确保只影响黑白精简风主题

#### 兼容性保证
- 保持其他主题的样式不受影响
- 继续使用CSS变量系统的优势

## ✅ 修改效果

### 视觉改善
- ✅ **对比度增强**：表头背景色明显深于内容区域
- ✅ **层次清晰**：表头与内容区域有明确的视觉分离
- ✅ **主题一致**：与TopBar使用相同的深灰色，保持界面统一

```

修改后：
```

### 设计一致性
