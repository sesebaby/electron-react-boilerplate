# 系统初始化功能说明

## 功能概述

系统初始化功能允许管理员重置整个系统到初始状态，包括清空业务数据、重建数据库结构、导入默认数据等操作。此功能主要用于系统维护、测试环境重置或数据清理。

## 功能位置

系统初始化功能位于：**系统管理** → **系统初始化** 标签页

## 主要功能

### 1. 系统状态监控
- **数据表数量**：显示当前数据库中的表数量
- **数据记录数**：显示所有表中的总记录数
- **数据库大小**：显示数据库文件的大小
- **备份文件数**：显示现有备份文件的数量

### 2. 数据库备份
- **自动备份**：在执行初始化前自动创建数据库备份
- **备份描述**：可以为备份添加自定义描述
- **时间戳**：备份文件名包含创建时间戳
- **备份管理**：可以查看、验证和删除历史备份

### 3. 初始化选项
- **创建备份**：是否在初始化前创建数据库备份（推荐开启）
- **保留用户**：是否保留现有的用户账户信息
- **保留设置**：是否保留系统基础设置和配置
- **导入示例数据**：是否在初始化后导入默认的示例数据

### 4. 系统初始化流程
1. **备份阶段**：创建当前数据库的完整备份
2. **清理阶段**：清空指定的业务数据表
3. **结构重建**：重新创建数据库表结构
4. **数据导入**：导入默认的示例数据（如果选择）
5. **服务初始化**：重新初始化系统服务

## 使用步骤

### 1. 访问功能
1. 登录系统管理员账户
2. 进入 **系统管理** 页面
3. 点击 **系统初始化** 标签页

### 2. 配置选项
1. 检查当前系统状态信息
2. 根据需要配置初始化选项：
   - ✅ **建议开启**：创建备份、保留用户、保留设置
   - ⚠️ **谨慎选择**：导入示例数据（会覆盖现有业务数据）

### 3. 执行初始化
1. 点击 **执行系统初始化** 按钮
2. 仔细阅读确认对话框中的警告信息
3. 确认操作后果，点击 **确认初始化**
4. 等待初始化完成（过程中会显示进度）

### 4. 完成后操作
1. 系统会自动刷新页面
2. 重新登录系统
3. 验证系统功能是否正常

## 安全措施

### 1. 二次确认机制
- 执行前会显示详细的操作说明
- 需要用户明确确认才能执行
- 清楚说明操作的不可逆性

### 2. 自动备份
- 默认在初始化前创建完整备份
- 备份文件包含时间戳便于识别
- 备份成功后才会继续初始化流程

### 3. 数据保护选项
- 可选择保留用户账户信息
- 可选择保留系统基础设置
- 避免完全丢失重要配置

### 4. 进度监控
- 实时显示初始化进度
- 详细的状态信息和错误提示
- 如果失败会显示具体错误原因

## 注意事项

### ⚠️ 重要警告
1. **数据不可恢复**：初始化会永久删除业务数据，请确保已做好备份
2. **系统停机**：初始化过程中系统不可用，建议在维护时间执行
3. **权限要求**：只有系统管理员才能执行此操作
4. **网络稳定**：确保网络连接稳定，避免初始化过程中断

### 💡 最佳实践
1. **定期备份**：建议定期手动创建数据库备份
2. **测试环境**：先在测试环境验证初始化流程
3. **文档记录**：记录初始化的原因和时间
4. **团队通知**：提前通知相关团队成员

## 故障排除

### 常见问题
1. **备份失败**：检查磁盘空间是否充足
2. **初始化中断**：检查网络连接，可尝试重新执行
3. **权限错误**：确认当前用户具有管理员权限
4. **数据库锁定**：确保没有其他程序正在使用数据库

### 恢复方案
1. **从备份恢复**：使用自动创建的备份文件恢复数据
2. **重新初始化**：如果初始化失败，可以重新执行
3. **联系技术支持**：如遇到无法解决的问题，请联系技术支持

## 技术实现

### 后端服务
- `DatabaseBackupService`：数据库备份服务
- `SystemInitializationService`：系统初始化服务
- Electron IPC 处理器：主进程数据库操作

### 前端组件
- `SystemInitialization.tsx`：系统初始化UI组件
- 进度指示器和状态反馈
- 确认对话框和用户交互

### 数据库操作
- 完整数据库备份和恢复
- 选择性数据清理
- 数据库结构重建
- 示例数据导入
