# 📱 响应式设计使用指南

## 🎯 概述

本指南介绍如何在项目中正确使用响应式设计功能，确保在所有设备上提供最佳用户体验。

## 🔧 核心功能

### 1. 响应式断点系统

项目使用标准的响应式断点：

```css
/* 移动端 */
@media (max-width: 768px) { }

/* 平板设备 */
@media (max-width: 1024px) and (min-width: 769px) { }

/* 小屏幕高度 */
@media (max-height: 600px) { }
```

### 2. 触摸友好设计

所有交互元素遵循44px最小触摸目标：

```tsx
// 正确的按钮实现
<button className="min-h-[44px] min-w-[44px] touch-manipulation">
  点击我
</button>
```

### 3. 移动端优化类

使用专用CSS类优化移动端体验：

```tsx
// 移动端全屏模态框
<div className="popup-dropdown modal-fullscreen-mobile">
  {/* 内容 */}
</div>

// 可隐藏的表格列
<th className="table-column-optional">
  可选列
</th>

// 触摸友好间距
<div className="mobile-touch-spacing">
  <button>按钮1</button>
  <button>按钮2</button>
</div>
```

## 📋 开发规范

### 1. 组件开发

**导航组件**：
```tsx
// 移动端适配示例
const Sidebar = ({ collapsed, onToggle }) => {
  return (
    <div className={`
      fixed left-0 top-0 h-full z-40 transition-all duration-300
      ${collapsed ? 'w-16' : 'w-64'}
      md:translate-x-0 ${collapsed ? '-translate-x-full md:translate-x-0' : '-translate-x-full md:translate-x-0'}
    `}>
      {/* 内容 */}
    </div>
  );
};
```

**表格组件**：
```tsx
// 响应式表格容器
<div className="table-scroll-root overflow-auto">
  <table className="standard-table">
    <thead>
      <tr>
        <th>必要列</th>
        <th className="table-column-optional">可选列</th>
      </tr>
    </thead>
  </table>
</div>
```

**模态框组件**：
```tsx
// 响应式模态框
<div className="popup-overlay flex items-center justify-center p-2 sm:p-4">
  <div className="popup-dropdown max-w-md w-full sm:max-w-md md:max-w-lg">
    {/* 内容 */}
  </div>
</div>
```

### 2. 样式规范

**使用CSS变量**：
```css
/* 正确 */
.my-component {
  color: var(--text-primary);
  background: var(--surface-background);
  border: var(--glass-border);
}

/* 错误 - 避免硬编码 */
.my-component {
  color: white;
  background: rgba(255, 255, 255, 0.1);
  border: 1px solid #ffffff20;
}
```

**触摸友好设计**：
```css
.touch-element {
  min-height: var(--touch-target-min, 44px);
  min-width: var(--touch-target-min, 44px);
  touch-action: manipulation;
}
```

## 🔍 调试技巧

- 检查CSS媒体查询应用情况
- 验证触摸目标尺寸

### 2. 控制台测试

```javascript
// 检查当前断点
const getCurrentBreakpoint = () => {
  const width = window.innerWidth;
  if (width <= 768) return 'mobile';
  if (width <= 1024) return 'tablet';
  return 'desktop';
};

// 检查触摸友好性
const checkTouchTargets = () => {
  const buttons = document.querySelectorAll('button');
  buttons.forEach((btn, i) => {
    const rect = btn.getBoundingClientRect();
    if (rect.width < 44 || rect.height < 44) {
      console.warn(`按钮 ${i} 尺寸不足: ${rect.width}x${rect.height}px`);
    }
  });
};
```
