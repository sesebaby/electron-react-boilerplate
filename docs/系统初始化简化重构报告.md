# 系统初始化简化重构报告

## 概述

根据用户要求，成功完成了Electron应用系统初始化流程的简化重构，移除了备份功能，改用内置数据替代外部SQL文件，提高了初始化的可靠性和简化程度。

## 重构内容

### 1. 移除备份功能

**修改文件：**
- `src/services/systemInitializationService.ts`
- `src/components/System/SystemInitialization.tsx`

**主要变更：**
- 移除了 `InitializationOptions` 中的 `createBackup`、`backupDescription`、`importMockData` 属性
- 移除了 `InitializationProgress` 中的 `backupInfo` 属性
- 简化了初始化流程，从5个步骤减少到4个步骤：
  1. 清理数据库 (10-30%)
  2. 重建数据库结构 (35-50%)
  3. 导入内置初始数据 (55-75%)
  4. 重新初始化系统服务 (80-95%)

### 2. 内置数据替代外部SQL文件

**新增功能：**
- 在 `public/database/handlers/systemHandlers.js` 中添加了内置数据导入功能
- 创建了 `db-import-builtin-data` IPC处理器替代 `db-import-mock-data`

**内置数据包含：**
- **41个单位数据**：涵盖数量、重量、长度、体积、面积、时间等6大类型
- **10个分类数据**：包含层级关系的商品分类
- **5个供应商数据**：完整的供应商信息
- **4个仓库数据**：不同类型的仓库配置
- **28个转换规则**：单位间的转换关系

## 解决的问题

### 1. 文件依赖问题
- **原问题**：依赖外部 `mock-data.sql` 文件，路径解析复杂
- **解决方案**：使用内置JavaScript数据定义，无文件依赖

### 2. 备份功能复杂性
- **原问题**：备份创建失败导致整个初始化失败
- **解决方案**：完全移除备份功能，简化流程

### 3. 异步操作错误传播
- **原问题**：Generator.throw错误导致连锁反应
- **解决方案**：简化异步操作链，减少错误传播点

### 4. 路径计算错误
- **原问题**：mock-data.sql文件路径计算不正确
- **解决方案**：不再需要文件路径，使用内存数据
