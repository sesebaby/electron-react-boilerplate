## 2. 入库管理流程图

详细的入库业务流程，包含各种入库类型和完整的业务操作步骤。

```mermaid
flowchart TD
    A[开始入库] --> B[选择入库类型]
    
    B --> C{入库类型}
    C -->|采购入库| D[采购入库流程]
    C -->|生产入库| E[生产入库流程]
    C -->|调拨入库| F[调拨入库流程]
    C -->|其他入库| G[其他入库流程]
    
    %% 采购入库流程
    D --> D1[选择采购订单]
    D1 --> D2[验证订单状态]
    D2 --> D3{订单可入库?}
    D3 -->|否| D4[显示订单状态错误]
    D4 --> D1
    D3 -->|是| D5[创建采购入库单]
    
    %% 通用入库流程
    D5 --> H[填写入库单信息]
    E --> H
    F --> H
    G --> H
    
    H --> H1[设置入库仓库]
    H1 --> H2[添加入库商品]
    H2 --> H3[选择商品]
    H3 --> H4[输入入库数量]
    H4 --> H5[设置入库单价]
    H5 --> H6[计算入库金额]
    H6 --> H7[添加商品备注]
    
    H7 --> I{继续添加商品?}

    I -->|否| J[验证入库单]
    
    J --> J1{数据验证}
    J1 -->|失败| J2[显示验证错误]
    J2 --> J3[修正数据]
    J3 --> J
    
    J1 -->|成功| K[单位换算处理]

    K2 --> K3[验证换算结果]
    K3 --> K4{换算正确?}

    K5 --> K2
    K4 -->|是| L[提交入库单]

    L1 --> L2[更新商品库存]
    L2 --> L3[记录库存事务]
    L3 --> L4[更新商品成本]
    L4 --> L5[更新采购订单状态]
    L5 --> L6[生成入库凭证]
    L6 --> L7[触发库存预警检查]
    L7 --> L8[发送入库通知]
    L8 --> M[入库完成]

    style M fill:#c8e6c9
```
